# GitHub Copilot Integration

Repository-level instructions are provided in `../../.github/copilot-instructions.md`.

That adapter intentionally contains a concise Engineering Focus summary rather than a second full copy of the canonical specification.

For a project adopting Engineering Focus, use repository instructions to point Copilot toward the canonical policy available to that project/runtime and select the desired default mode.

## Initial status

The repository-instruction adapter exists. Conformance tests should verify that the target GitHub Copilot experience actually applies the expected behavior before support is described as complete.
